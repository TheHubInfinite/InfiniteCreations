INFINITE CREATIONS — WEBSITE (ready for Netlify)

HOW TO PUBLISH
1. Unzip this folder.
2. Go to app.netlify.com -> Add new site -> Deploy manually.
3. Drag the whole unzipped folder (the one containing index.html) into the box.
4. Open the live link, send yourself a test enquiry and check it arrives.

WHEN YOU HAVE YOUR DOMAIN
Search every file for  infinitecreations.in  and replace it with your real domain
(index.html, privacy-policy.html, robots.txt, sitemap.xml). Then in Netlify:
Domain management -> Add a domain, and follow its DNS steps.

FILES
index.html          main website
privacy-policy.html privacy policy (served at /privacy-policy)
404.html            custom "page not found" page (Netlify uses it automatically)
_headers            security headers and caching (Netlify reads this file)
_redirects          clean URL for the privacy policy
robots.txt, sitemap.xml   search engine files
og-image.png        picture shown when the link is shared
favicon.*, apple-touch-icon.png, icon-*.png, site.webmanifest   icons
fonts/              self-hosted DM Sans and Space Grotesk (open-source licences included)
